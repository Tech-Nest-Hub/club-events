# Zapier: Prerequisites & Getting Started

> [!NOTE]
> Zapier connects apps so one thing happening in App A automatically
> triggers an action in App B. No hosting, no code, all in the browser. The official from zapier is [here](https://zapier.com/resources/guides).

## prerequisites

- A Zapier account (free tier)
- Accounts for the apps you want to connect (Gmail, Sheets, Slack, etc.)

## know these terms

- **Zap**: one automation (trigger + action)
- **Trigger**: the event that starts it
- **Action**: what happens as a result
- **Task**: each trigger/action run, counted against your plan limit

> [!WARNING]
> Test before going live. Check your plan's task limit, a busy Zap can burn
> through it fast. Some apps need an API key, not just a login.

## getting started

1. Sign up at [zapier.com](https://zapier.com)
2. Click "Create Zap"
3. Pick a trigger app and event
4. Connect your account for it
5. Add an action (app + what happens)
6. Test it, then turn the Zap on
